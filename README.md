# Wanderlight

《漫游微光》是一款双语、持续存档的开放世界文字 RPG。玩家沿轻幻想海岸工作、旅行、休息并结识成年人；地点、时间、物品、承诺、关系事件和长期角色的视觉身份会跨次保留。

游戏采用作者开场骨架、本地权威领域规则与 Aigram 持续叙事结合的结构。运行时图片由 AlterU Media Service 生成，并使用稳定角色身份锚点维持跨地点视觉一致性。

## 本地运行

```bash
npm install
npm run dev
```

## 构建

```bash
npm run build
```

项目文档位于 `doc/requirements.md`、`doc/visual.md` 与 `doc/technical.md`。
