# Screen Contract

## Entry / Continue

- **玩家问题**：这是什么世界，我现在从哪里开始或继续？
- **主焦点**：灯湾码头环境与一句开放世界承诺。
- **主操作**：进入世界或继续最近锚点。
- **次操作**：语言、声音、确认重开。
- **恢复**：存档未加载时主操作禁用并显示具体状态。

## Core Story

- **玩家问题**：刚才的行动造成了什么，我现在能做什么？
- **主焦点**：最新可见事件；图片只服务于该事件。
- **主操作**：三个基于当前事实的具体选择之一。
- **次操作**：自由输入、同行/路线/行囊/旅记抽屉。
- **持久信息**：世界名、地点/时刻、精力/旅费/风闻。
- **临时反馈**：权威数值变化、关系事件、人物身份固化状态。
- **恢复**：生成或网络失败不清空上一组选择。

## Character Drawer

- 只显示已经可见介绍的角色。
- 每行显示姓名、成年人身份/角色、最后位置和最近一条关系事实。
- 固化角色显示稳定身份缩略图；未固化动态角色显示“尚未留下清晰印象”，不是空头像。
- 不显示爱心或单一好感条。
- 不显示人物“活力/压力/技能 +n”等战斗型通用数值；详情以最近所在、擅长事项、共同经历与视觉印象为主。

## Header / Travel Dashboard

- 顶部恰好三个等宽工具：文字大小、声音、旅途手册。图标采用同一视框、描边和交互状态。
- 精力、旅费、风闻位于浅色票券条中，三项都显示可比较的短进度轨；点按数值才把对应状态卡放在详情首位。
- 从旅途手册按钮进入时，默认先看到当前目标和旅程概况，再看到数值状态，避免把本作误读为战斗角色面板。
- 旅程概况优先显示地点/时刻、已发现地点、认识的人、正在同行与行囊数量。

## Visual Identity States

- `unanchored`：临时人物，不允许后续清晰特写。
- `queued`：已经正式登场，身份锚点等待生成。
- `generating`：正文继续可玩，人物行显示非阻塞进度。
- `anchored`：身份锚点任务 ID 已持久化；运行时解析任务图片后，后续人物镜头可使用 `edit`。
- `failed`：显示失败和重试；不改变角色关系与登场事实。

## Map / Transition

- 地图只显示已发现地点和连接。
- 跨地区必须先出现月线车厢或月台桥接，再显示新地点正文与选择。

## Responsive and accessibility

- 正文为可滚动主区域；选项随内容自然排列，不用固定底栏遮挡文本。
- `320×568` 下允许 HUD 换行或横向内部滚动，但页面本身不得横向溢出。
- 所有控件提供焦点、按下、禁用和可访问名称；减少动态移除位移与缩放。
