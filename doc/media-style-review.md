# 自有媒体服务画风评审

## 1. 评审目的

本轮不比较不同出图供应商，只验证 AlterU 自有媒体服务在《Wanderlight》中的真实上限。所有样张均使用正式公共接口、永久游戏 session ID `66263f04-c6a5-4290-85f2-1011bbccf697`，没有使用 ImageGen 产物作为参考图。

原始入口提示词的问题不是单纯“描述不够长”，而是同时要求复杂群像、多个叙事线索、电影级光影与细节，超出了当前服务最稳定的表达区间。本轮把提示词改为：

1. 先声明媒介结构，而不是只追加一个风格名；
2. 固定一个主要人物、一个主体建筑和一个远景地标；
3. 明确三层构图、镜头距离和不可出现内容；
4. 将角色身份锚点与剧情动作图分开；
5. 用单参考 `edit` 验证跨地点连续性。

## 2. 候选与样本

第一轮入口同题测试 8 种方向：

- 32-bit 像素风
- 编辑水彩
- 美式成人图像小说
- 编辑水粉
- 欧式线描漫画
- 版画 / 丝网印刷
- 成人绘本式粉彩厚涂
- 纸艺拼贴

第二轮对像素、水彩、美式漫画、水粉、欧式线描生成同一名成年角色的身份锚点，再分别用该锚点续画到雨夜葡萄园。第三轮以完全不同的成年男性角色压力测试像素、水彩、美式漫画和水粉，验证发型、眼镜、年龄、外套与票夹是否能跨场景保留。

## 4. 观察与结论

### 推荐：编辑水粉

水粉在入口场景、女性角色、男性角色与两次不同地点续画中都保持了稳定的媒介感。它能提供足够的成人感与环境气氛，同时不会像写实概念图一样让单张图片压过文字。人物从锚点缩小到环境中后仍可通过发型、服装色、眼镜、发夹和坠饰辨认，适合 RPG 高频生成。

### B 方向：美式成人图像小说

美式漫画的轮廓和身份连续性最强，也最容易让玩家感到“这是一个游戏世界”。缺点是交叉排线与高对比轮廓会自然增加悬疑、硬派和戏剧张力。若后续把世界改得更危险、更都市，它可能优于水粉；在当前轻松幻想定位下暂列第二。

### 高质但需约束：编辑水彩

水彩的单张入口和旅行气质最好，但模型会主动戏剧化面部伤痕，且湿边和写实脸部细节的强度变化较大。它适合作为日志插页、回忆或稀有章节图，不宜在当前证据下承担全部角色身份资产。

### 独立产品方向：像素风

像素风的构图与身份特征保留很好，批量风格也稳定，但面部微表情带宽较低。它不是低质量备选，而是更强调探索、系统与怀旧感的另一款产品方向；不建议与水粉在同一世界中混用。

## 5. 角色视觉协议修正

测试发现模型会把“浅疤”放大成明显伤痕，水彩尤其显著。修正版用铜发夹替换浅疤后，水粉续画稳定保留了短发轮廓、发夹、外套色与种荚坠饰。因此：

- 身份锚点优先使用发型轮廓、眼镜、发夹、耳饰、坠饰、票夹和主服装色；
- 疤痕、胎记、纹身等面部/皮肤标记只在叙事必要时使用，并视为高敏特征；
- 每人保留 3–5 个跨镜头可见的身份特征，不堆叠文学性细节；
- 首次锚点使用单人 `text`，后续清晰出场均以该任务输出执行单参考 `edit`；
- 场景图保持一个身份所有者和一个主要动作；多人关系优先通过肩后、视点、背影与距离表达。

## 6. 建议决策

《Wanderlight》默认采用编辑水粉。正式画风前缀应固定为短而可复用的结构：

> EDITORIAL GOUACHE PAINTING, opaque matte brush shapes, visible dry-brush edges, simplified but observant adult features, deep indigo, mineral teal, sage and warm copper palette, sophisticated contemporary travel illustration, no glossy 3D, no photorealism.

不再使用最初的复杂电影概念图提示词，也不把 ImageGen 的细节密度作为自有服务必须追赶的视觉承诺。美式图像小说保留为 B 方向；水彩保留给特殊日志插页的后续实验。未经额外评审，不在同一局中随机混用风格。

## 7. v1 扩展素材证据

v1 扩展继续只使用 AlterU Media Service，并为新增地区与两名核心角色生成正式内部 QA 资产。公开材料不列出任务 ID 或服务结果 URL。

目视复验确认：罗温保留短卷发、窄边眼镜、靛蓝外套和银色票夹；塞莱斯特保留赤褐侧辫、右耳单枚耳扣和陶红披肩。三个新环境具有不同地标，未回退到灯湾雨街、开场行李或发光种荚。远灯环境样张出现少量远景成年人，与成人研修院设定一致；没有制服化未成年校园符号。

浏览器 QA 最初发现罗温图片为空，最终定位为测试夹具在图片请求之后注册路由的竞态，而非媒体服务或产品加载失败。夹具改为预注册 `https://qa.wanderlight/**` 后，罗温、塞莱斯特和媛夕六条双语路线的图片均进入 `ready`，新截图不再出现空图或替代文字。
