# Requirements — v1 完整版

## 1. Overview

《漫游微光 / Wanderlight》是一款手机优先、持续存档的开放世界文字 RPG。玩家来到由港城、葡萄丘、雾林、潮汐群岛、夜市和成人研修院组成的轻幻想海岸，可以接工作、旅行、吃饭、休息、结识成年人，并自行决定一段关系停留在陌生、熟悉、同行、竞争或暧昧中的哪一步。

### Game Profile

- **单次体验形态**：开放式探索为主、短事件为辅。一次打开可以完成 3–8 个回合，也可以持续游玩。
- **期望投入**：首次体验约 8–15 分钟；回流玩家可在一个自然场景结束后停止。
- **跨次连续性**：持续叙事世界。地点、时间、物品、钱币、关系事件、承诺、角色去向以及角色视觉身份都保留。
- **持久状态**：完整世界存档、三项数值、地图、物品、已介绍角色、同行者、关系事件和每个长期角色的视觉身份记录。
- **自然停止点**：旅店休息、月线车厢、车站月台、完成一份工作或明确告别之后。
- **回访理由**：继续未完成的工作或旅程；寻找已经认识的人；看看偶遇是否会成长为稳定关系。

### 适用承诺层级

- **发现承诺**：一个比恋爱菜单更宽广的轻幻想世界；关系是探索的结果，不是唯一目标。
- **首个有效动作**：玩家在灯湾码头选择挣钱、搭车或回应一个人的邀请，并立即看到地点、资源或关系事实变化。
- **首次体验**：三个开场方向都必须成立；玩家至少经历一次自由选择、一次人物正式登场、一次获得报酬或资源取舍、一次月线中转，以及一次与前一选择相关的重逢。
- **前 10 分钟**：认识三种不同生活方式，理解人物会记得承诺与边界，并亲历“离开—中转—换地—重逢”。
- **单次结束**：世界不强制结算；自然停止点明确说明已经保存到哪个地点和时刻。
- **长期承诺**：预设角色提供稳定深度，运行时角色可以从偶遇晋升为长期关系对象；玩家不被绑定到唯一主线或唯一攻略对象。

一句话核心玩法：**在自由旅行和谋生中选择把时间给谁，并通过可追溯的共同事件，让偶遇变成玩家真正记得的一段关系。**

## 2. Visual Design

- 使用累积阅读的响应式文字 RPG 界面，事件图片插入其对应叙事位置，不采用每步强制全屏换图。
- 视觉重心是“地方先存在，人物在其中生活”：环境建立镜头、人物身份锚点、反应镜头与月线中转镜头交替出现。
- 三名预设角色和运行时生成角色都必须拥有稳定视觉身份。未固化身份的临时 NPC 不得反复生成无参考的面部特写。
- 关系场景以距离、目光、动作、衣料、手部接触、共同劳动和空间选择表达暧昧，不依赖直白裸露或性行为。
- 主验收为 `390×844` 与 `320×568`，同时检查 `1024×768` 与 `1440×900`；外部访客栏不影响平台内主构图。
- 正式海报只允许英文 `WANDERLIGHT`，禁止中文、伪中文和生成式可读文字。
- 完整视觉系统见 `doc/visual.md`。

### 双语叙事语言

- 中文和英文都以“一遍读懂行动与因果”为底线，分别按各自自然句法创作，不做机械逐句直译。
- 质感来自具体动作、光线、声音、距离、停顿、手势、物件和人物潜台词；关键事实不得交给抽象隐喻承担。
- 每个短段主要推进一个新事实；每次最多引入一个陌生世界词，并在同句或下一句通过外形、用途或现场反应自然解释。
- 对话像当前处境中的成年人，不替作者讲世界观；选项使用直接动词，只引用已经可见的人、地点、物品或问题。
- 该标准同时约束作者预写内容与未来 AI 自由生成内容。生成正文不得出现“中转锚点、视觉身份、关系升温、剧情节点”等幕后设计语言。

## 3. Game Mechanics

### 核心循环

1. 读取当前地点、时间、可见人物、短期目标和最近关系事实。
2. 选择交谈/同行、探索/工作，或保护资源/边界；也可以输入自由行动。
3. 权威状态更新地点、时间、精力、钱币、风闻、物品或关系事件。
4. 叙事展示直接结果；图片导演在地点变化、正式登场、关系转折、任何说话者的重要对白或连续两回合无图时生成事件图。重要性由对白是否揭示关键事实、改变关系、设定边界、作出承诺/请求、警告危险、建立任务或形成明显情绪转折决定，不以人物是否属于预设主角判定。
5. 玩家根据新事实继续行动，或在月线车厢、旅店和工作结束处自然停止。

### v1 内容边界

- **正式区域**：灯湾码头、月线车厢、杯影夜市、银叶葡萄丘、雾杉林、潮汐群岛、远灯研修院。每个区域至少有一种工作/资源活动、一种社交活动、一种离开或休息方式，以及不会复用其他区域地标的图片语言。
- **开场三路**：帮助发光种荚进入媛夕路线；接夜班工作进入罗温路线；去夜市搬箱进入塞莱斯特路线。三路都在首回合明确人物、报酬和下一行动，不存在“假选项”。
- **三名核心角色**：媛夕、罗温、塞莱斯特各有可见首次登场、一次共同工作、一次跨地点重逢、一次边界或价值判断，以及同行/分别的可持久结果。玩家可以不发展亲密关系，也可以与多名角色保持不同性质的关系。
- **动态人物**：至少验证一名运行时人物从陌生外形与动作、名字来源、当前意图到稳定 ID、视觉锚点、人物面板和后续重逢的完整流程。
- **持续游玩**：作者内容负责建立世界和三条主入口；之后 Aigram 根据权威存档持续创造成年 NPC、工作、邀请、传闻和局部事件。未来生成内容必须遵守同一双语叙事、首次登场、月线中转、资源和视觉身份合同。

### 玩家可重复进行的活动

- **当地短工**：消耗 `10` 精力，获得 `9` 钱币与 `2` 风闻；精力低于 `12` 时不能开工，并给出吃饭、休息或轻量社交的可行选择。每份动态工作在报价时创建带稳定 ID、雇主和明确工资的权威合同；报价不入账，只有正文明确写到工作完成并按合同金额结算时才由本地 reducer 原子增加钱币。正文、合同与结算不一致时整回合不得写入存档。
- **吃一顿热饭**：花费 `4` 钱币，恢复 `12` 精力；钱币不足时不能透支，可选择短工、求助或不花钱休息。
- **住一晚**：花费 `10` 钱币，恢复 `28` 精力并形成自然停止点；存档保留，回来后从次日当前地点继续。
- **月线车厢休息**：在车厢内可免费恢复 `8` 精力，但时间推进且列车仍会抵达下一站；它不能替代长期住宿。
- **旅行**：跨区域先回到月台或月线车厢，再抵达目的地。普通车程花费 `3` 钱币与 `2` 精力；通行册印章只用于停运后的特殊路线。

### 三项可见数值

- **精力**：`0–100`，初始 `72`。工作、夜行和赶路消耗；吃饭与休息恢复。低于 `28` 时限制高负荷行动，降到 `0` 不结束游戏，而是强制进入疲惫恢复并可能错过约定。
- **钱币**：初始 `6`，是普通可消费余额，不是需要攒满的进度目标。普通车票 `3`、热饭 `4`、客房 `10`；工作、交易和已结清委托增加。HUD 不显示上限或进度轨，内部只保留不公开的异常保护边界。没有钱币时仍可通过帮工、步行或求助继续，但会改变时间与关系后果。
- **风闻**：`-40–100`，初始 `4`。它代表不同地区对玩家的公开印象，不是道德值或恋爱值；只由可见事件改变。

### 关系与角色

- 不显示单一“好感度”。关系由带来源的事件组成，例如守约、爽约、共同完成工作、保护边界、公开支持、撒谎或告别。
- 所有可发展亲密关系的角色明确为 `24+` 成年人。研修院是成人职业与魔法研修机构，不出现校园未成年人。
- 媛夕、罗温和塞莱斯特是三个预设核心角色，分别代表地方研究、月线旅行和夜市演出三种生活路径；他们不是强制攻略对象。
- AI 可以创造新的成年 NPC。新角色第一次只作为临时偶遇存在；只有完成可见正式登场、获得稳定角色 ID 并成功固化视觉身份后，才进入人物面板和长期关系系统。
- 运行时角色一旦固化，后续姓名、身份、锚点任务 ID、不可变特征、承诺、关系事件和最后位置进入权威存档，不能由模型静默重写。

### 角色视觉身份实验

- 每个长期角色都有一个 `visualIdentity`：稳定角色 ID、身份状态、身份锚点任务 ID、身份版本、不可变特征、服装版本和禁止漂移项。服务返回的临时图片 URL 只在运行时解析，不作为持久身份真源。
- 首次正式登场会安排一个单人物、中近景、脸和轮廓可读的身份锚点。预设角色使用已配置锚点任务；动态角色先以文本模式生成锚点，成功后将任务 ID 固化，后续通过该任务解析参考图并执行 `edit`。
- 当前图片服务一次只支持一个参考。角色主导镜头只引用该角色；玩家主导镜头只引用玩家；空镜不引用。双人关系镜头使用正反打、视点镜头、背影、剪影或固定人物层，避免让两个清晰面孔同时依赖单参考生成。
- 身份生成失败不阻塞叙事。该角色仍可交谈，但在重试成功前不得继续生成无参考的清晰面部镜头。
- 垂直切片必须验证：首次登场、换地点、换光线、一次重逢、另一角色防串脸，以及一个运行时角色从临时到固化。

### 地图、中转与资源

- v1 包括灯湾码头、月线车厢、杯影夜市、银叶葡萄丘、雾杉林、潮汐群岛和远灯研修院。
- 跨地区移动必须先经过月线车厢或车站月台这一视觉与叙事锚点，再提交目的地叙事。
- `月线通行册` 有 3 枚一次性印章，可开启已发现路线的晚班车或小包厢；它是物品计量，不增加第四项 HUD 数值。

### 完成标准

- 这是持续世界，没有“看完全部 AI 文本”的穷举终点。v1 完成指：七个区域和三个核心角色进入权威世界合同，三个开场方向都有作者级完整入口，重复活动由本地规则稳定结算，AI 能在其上继续生成而不重置人物、资源、地点或语言风格。
- 发布前必须分别试玩中文和英文的媛夕、罗温、塞莱斯特三条入口路线；验证一条合法短工、一条精力不足拒绝、一顿饭、一次住宿停止、一次月线中转、一次动态角色固化和一次刷新恢复。

### 压力、失败与恢复

- 普通探索至少持续 3 回合后才可能进入警告；5 回合内若没有压力事件则进入一次世界相关警告，解决后冷却 3 回合。
- 不使用物理战斗。压力来自末班车取消、银雨封路、雇主改约、公开误解或重叠承诺。
- 玩家可以询问和理解、承担成本保护某人，或撤退/改道/设定边界。
- 失败产生疲惫、错过交通、钱币损失、尴尬、关系受损或路线改变；不删除存档，不强制绑定任何关系。

### 待验证实验

| 问题 | 基线 | 干预 | 可观察信号 | 通过信号 | 停止信号 | 下一步 |
|---|---|---|---|---|---|---|
| 同一 NPC 换场景后还能否被认出 | 仅重复文字外貌提示 | 固定参考图 + `edit` + 单身份镜头 | 遮住名字后的角色辨认、关键特征保留 | 4 个测试场景中至少 3 个可稳定认出且无串脸 | 连续两次重逢无法辨认或串成另一核心角色 | 改用固定人物层，不扩展内容 |
| 动态 NPC 能否从偶遇晋升为长期角色 | 模型每次重新描述 NPC | 首次正式登场后固化角色 ID 与锚点任务 ID | 重载、换地点、重逢后的档案与形象 | 存档恢复后仍使用同一 ID 与任务锚点 | 任务锚点丢失、刷新后重建或角色重复 | 修复持久化再继续 |
| 单参考限制下关系镜头是否仍有吸引力 | 两张清晰正脸的自由生成 | 正反打、视点和动作细节 | 是否能理解两人关系与当前动作 | 不依赖姓名也能说出谁在做什么 | 镜头含混或不断回退为头像摆拍 | 引入固定人物层合成 |

## 4. Controls

- 叙事正文纵向滚动；选择卡和自由输入使用 `onClick`/提交动作，不在滚动列表里使用 `onPointerDown`。
- 每回合最终采用的行动必须以 `01 / 02 / 03` 同步写入正文记录，并在底部当前行动卡显示同一编号与同一文案；两处使用同一份权威选择数据，不允许模型正文与结构化命令各自维护一套选项。
- 顶部笔记本图标直接打开旅途手册的“人物关系”页；入口与文字大小、声音图标保持相同的尺寸和垂直对齐，不附加可见文字。关系页先显示关系总览，再按同行者与旅途中认识的人分组。每个人物行必须直接显示当前关系印象与共同经历数，点开后关系摘要位于人物详情首屏，完整关系记录继续向下展开。
- 每个生成回合必须把有效地点、新任务、底部选项和新事件图作为一个原子结果提交：正文抵达新地点时同步更新地图，新任务同步更新目标，选项只能作用于当前地点，事件图必须声明并使用同一地点。任一部分仍指向旧场景时整回合不得写入存档。
- 玩家可以点击底部行动卡，也可以在自由输入框提交 `1 / 01 / 2 / 02 / 3 / 03` 执行对应的当前行动；超出当前选项数量的数字和普通文字仍按自由行动处理。
- 恢复已有存档时，“继续游戏”必须定位到上一轮玩家行动与随后的剧情上下文，而不是滚动容器的物理底部；恢复后的首屏应同时看见可读剧情，底部当前行动卡保持可操作。
- 点击一个选择立即显示本地按下反馈并锁定重复提交；模型、图片和存档不能阻塞第一层反馈。
- 同行、路线、行囊和旅记通过顶部旅途手册进入；关闭后回到原阅读锚点。
- 支持中文与英文；所有按钮、标签、错误和恢复操作跟随玩家语言。
- 键盘用户可以按顺序聚焦选项、输入框和抽屉控件；移动端触控目标至少 `44×44 CSS px`。

## 5. Win / Lose Conditions

- 游戏没有传统胜利、Game Over 或唯一结局。
- 完成工作、抵达新地区、确认一段关系边界、与某人同行或分别，都是局部完成状态。
- 精力归零、钱币不足、错过交通或关系受损会改变后续路线，但不会删除进度。
- 月线车厢、旅店休息和完成工作是自然停止点；返回时从最近权威状态继续。
- 真正结束一段关系必须由可见告别和结构化状态更新共同成立；玩家可以继续探索世界。

## 6. Sound Effects

- 所有生产音频由 Web Audio 程序合成，不依赖媒体服务生成的带声视频，也不播放隐藏视频。生成式音轨实验已证明会夹带音乐、响度不稳定且不适合循环，仅作为 QA 反例保存。
- 环境底：`19s` 双声道非重复噪声纹理，分成雨棚/玻璃的中高频层与木车厢低频层，循环边界做 `1.4s` 交叉融合；每 `7–17s` 最多出现一次轻雨滴、远轨缝或车厢沉降细节，不形成旋律。
- 普通选择：纸张擦动 + 很轻的木质票夹触点，总长不超过 `180ms`，输入后立即开始。
- 钱币增加：一枚金属触点的非整数泛音 + 木桌接触，约 `420ms`；钱币花费使用更闷、更短的衰减，不能与增加同声。
- 精力、风闻、关系、普通物品和稀有物品使用不同材质组合；不再共用同一个电子“叮”或上行音阶。
- 月线中转：相隔约 `340ms` 的两次轨缝触点 + 约 `1.05s` 低频车厢共振，只在真实地点切换时播放一次。
- 出图完成：画笔擦过冷压纸的两层带通噪声 + 极轻触点，不使用电子双音。
- 成功、失败和错误共享木质语言，以共振明暗、衰减和重复次数区分，不使用夸张胜利/失败旋律。
- 背景音乐降到环境之下，16 拍内仅有稀疏持续和声与 `2–3` 个轻触点；不能形成抢正文的短循环。
- 音频必须在用户手势后解锁、后台暂停、失败非阻塞，并提供持久静音；静音时环境、音乐和一次性反馈全部停止。
