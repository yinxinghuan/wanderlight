# Interface Brief

## Product frame

- **玩家与场景**：希望在手机上持续探索、交友和建立关系的海外玩家；所有可亲密角色均为成年人。
- **单次活动**：阅读当前事件，选择或输入行动，查看地点、资源、人物与关系事实的后果。
- **单次形态**：开放式探索，夹杂短工作、旅行和关系事件。
- **持续性**：完整世界、角色身份与关系事件跨次保留。
- **主要焦点**：当前可见事件，以及玩家下一步把时间给谁或给什么。
- **情绪承诺**：轻松、自由、带一点暧昧，但人物和世界都具有真实连续性。

## Promise horizons

- 第一次行动必须改变地点、资源或关系事实之一。
- 首次体验包含人物登场、月线中转和重逢。
- 十分钟内理解预设角色不是菜单、动态角色可以被世界记住。
- 自然停止时明确保存位置与时刻。

## Screen and state inventory

- **入口/继续**：世界封面、当前存档锚点、进入/继续/确认重开。
- **核心游戏**：顶部世界与 HUD、累积正文、内联事件图、权威变化条、选择和自由输入。
- **抽屉**：同行、路线、行囊、旅记组成的旅途手册；默认总览优先显示目标、发现地点与同行关系，而不是系统段落数。
- **生成状态**：身份锚点等待、图片生成、失败与重试；都不阻塞文字行动。
- **错误恢复**：模型失败保留上一组选择；身份生成失败保留人物档案但限制无参考特写。
- **停止状态**：月线、旅店或工作结束处显示已保存锚点，无强制结算。

## Environment

- AlterU WebView 与外部浏览器；平台内无访客栏占位。
- 响应式 DOM，纵向滚动；`390×844` 和 `320×568` 为主。
- Touch、pointer、keyboard；滚动内容中的卡片使用 `onClick`。
- 支持 `zh/en`，安全区、长字符串、减少动态和静音。

## Content and assets

- 三名预设成年角色、运行时固化角色、七个可探索地区和月线中转站。
- 一套线性 SVG 图标；不使用 Emoji 功能图标。
- 运行时场景图和身份锚点；玩家图像只在玩家主导镜头使用。
- 图片失败时必须有文本替代和明确重试。

## Direction inputs

- 使用旅行杂志、夜班列车和矿物色轻幻想的原则。
- 明确排除酒店式情色、未成年校园感、攻略头像列表、粉紫玻璃拟态和 AI 伪文字。
- 当前锁定方向为“会生长的夜行旅途日志”。
