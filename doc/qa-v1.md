## 规则与内容测试

- `test:protocol`：英文所有格不再截断结构化选项；首次登场、同行添加/移除和长历史恢复通过。
- `test:danger`：危险节奏、固定本地掷骰、失败成本与恢复通过；新存档前六个场景为首轮宽限，检查点不叠加随机危机。
- `test:identity`：动态角色塔林从可见登场到锚点任务与重逢引用通过。
- `test:narrative`：所有中英文作者回合有三项落地选择或明确检查点；未来 Aigram/remote 生成均注入清楚而不晦涩的双语合同。
- `test:domain`：短工、精力拒绝、餐食、住宿、跨日时钟与旅行原子结算通过。
- `test:routing`：三个开场方向不会被通用关键词或普通车票规则串路。
- `test:outcomes`：三名角色×双语的同行者、关系来源与停止点通过。
- `test:regions`：五个可购票目的区域都提交独立地图状态、工作/社交/休息事实和 `new-location` 环境图；无开场画面残留。

- 图片加载竞态只存在于旧 QA 夹具；预注册图片路由后，Rowan 空图复验通过。
- 390×844 英文与 320×568 中文代表状态均无横向溢出。
- 2026-08-13 UI 打磨后再次完整点击媛夕中文 `320×568` 与罗温英文 `390×844` 路线：顶部三个工具保持 `44×44` 同系列图标，浅色票券 HUD 无溢出；普通旅途手册入口按“目标 → 旅程概况 → 状态”排列。
- 同行页已移除活力/压力/技能加值，只显示身份、最近地点、共同经历和擅长事项；路线页只显示已发现地点，编号与路线节点不重叠。
- 最终 UI 证据已在内部档案保留中文 `320×568` 与英文 `390×844` 的旅途总览、人物和路线页。
- 新版结尾不再出现与当前作者路线无关的压力判定卡。
- 编辑水粉风格、成人年龄表现、人物识别物和地点地标保持一致；没有中文封面、伪文字、未成年校园符号或软色情直白视觉。
